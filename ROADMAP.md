# Roadmap

1. Bootstrap and safety kernel: domain contracts, risk, OMS, paper execution,
   accounting, audit, deterministic tests.
2. Versioned market-data platform: instrument master, calendars, corporate
   actions, point-in-time semantics, Parquet/DuckDB, quality gates.
3. Research and portfolio baseline: factors, chronological experiments,
   metrics, reproducibility, baseline strategies.
4. Event-driven backtest integrated with the same risk/OMS/execution path.
5. Paper runtime: realtime adapters, recovery, reconciliation, failure injection.
6. FastAPI control plane, role separation, dashboard, metrics and alerts.
7. Shadow mode and live-readiness audit. Real trading remains disabled.

See `plans/MASTER_PLAN.md` for acceptance evidence and current sequencing.
