# QTrade 页面职责与时间口径

更新：2026-10-27。本文对应统一目标池行情接入后的页面设计；生产部署身份和实测结果另见当日验收记录。

## 从哪里开始看

| 页面 | 主要回答的问题 | 应核对的身份和日期 |
| --- | --- | --- |
| 总览 `#/` | 采集、模型、预测、前向观察分别处于什么状态？ | 统一证券池版本、最近完整日、ACTIVE、预测、心跳与网页代码版本 |
| 行情中心 `#/market` | 指定目标证券实际取得了哪些已完成行情？ | 证券代码、频率、查询窗、行情发布版本、实际截止与当前应覆盖时点 |
| 数据中心 `#/data` | 目标池、已采集覆盖、质量隔离和历史回补差多少？ | 目标与覆盖的分母、质量原因、历史范围、证券主表与版本 |
| 策略中心 `#/strategies` | 有哪些固定研究协议、模型和策略可使用？ | 策略规格、数据与模型、限制；目录不是当前执行结果 |
| 策略研究 `#/research` | 如何登录、选择受支持的配置并提交研究任务？ | 时间切分、标签、特征、模型、成本与提交后的任务身份 |
| 实验中心 `#/experiments` | 任务有没有执行、失败、完成或归档？ | 任务状态、固定规格、执行器心跳、原始测试区间和完成时间 |

| 在线模型 `#/models` | 正式日版本、ACTIVE 与候选模型分别是什么？ | 数据截止、版本、冻结处理器、验证、审批、周期政策和预测归档 |
| 每日研究信号 `#/signals` | 哪次预测产生了哪些研究排序和目标？ | 模型、数据、预测与信号清单绑定，预计执行时间和可用性 |
| 模拟交易 `#/paper` | 已冻结目标在真实后续会话中发生了什么？ | PAPER/SHADOW 模式、冻结时点、观察日、风险状态与恢复要求 |

| 系统监控 `#/monitor` | 原平台服务与持久审计是什么状态？ | 监控来源与原范围；当前统一业务链路同时查看总览和在线模型 |

## 五个时间不能混用

1. **行情时间**：Bar 代表的市场时点。五分钟 Bar 完成并经过交易日历宽限后才应纳入。午休、闭市和非交易日不会按自然时间不断要求新 Bar。
2. **采集时间**：实际收到原始响应并成功入库的时间。抓取成功不等于整个目标池已追齐。
3. **发布或心跳时间**：集群发布物和服务状态更新的时间。文件刚发布仍可能包含较旧行情；心跳有效也不等于预测可用。
4. **实验时间**：实验固定训练、验证、测试区间和执行完成时间。重新部署网页不会改变历史实验区间。
5. **网页代码版本**：Vercel 当前程序的 Git 身份。行情和实验发布使用独立只读通道，通常无需为每次数据更新重新构建网页。

时间统一按上海时区展示。查看查询范围内的旧日期不会让整个数据集被误判为旧数据；页面分别标出“所选范围最后一根”和“整个数据集实际截止”。

## 目标池、行情池、研究池和持仓池

- 1,500 是当前目标证券池，包含股票和 ETF；不是 A 股全部上市公司，也不等于已经取得完整历史的证券数。
- 统一行情只展示现有增量湖中实际通过准入的记录。公开查询上限为最近 20 个日线交易日、3 个五分钟交易日，实际可用历史可能更短。更长的集群研究存档不自动成为此接口的可查询历史。
- Qlib 正式版本有独立合格规则和实际股票数，不能把 1,500 目标数量填作模型输入数量。
- 策略目标、模拟实际持仓和 SHADOW 观察是不同对象。SHADOW 只有目标与后来行情观察，没有成交、持仓、净值或组合收益。

## 刷新和异常应如何理解

总览按来源分别请求：统一采集目录与网页身份约 60 秒，在线模型约 15 秒，股票与 ETF 前向状态约 30 秒；行情页面约 60 秒请求选中证券。后台实际采集、发布和日版本任务有自己的周期，网页轮询不会加速这些任务。

新行情索引超过 180 秒会明确标为发布过期；目录与其他服务使用各自契约的阈值，不能统一套一个秒数。有效但陈旧的已验行情可以带显著警告作为历史查看；身份不符、版本变化、对象验证或请求失败时不显示该次无效图表，也不回退到旧池假装当前数据。

`PARTIAL` 表示仍有应到未到数据，`NO_DATA` 表示没有已准入记录，`QUARANTINED` 表示验证问题导致隔离。原始供应商错误不能直接解释成停牌、ST 或退市。成交额、VWAP、历史可得时点未知时保持空值；价格复权未认证、幸存者偏差及交易规则未知等限制随相应数据和实验保留。

## 如何增加因子、策略或模型

网页研究提交仅接受已实现并经过校验的受支持规格；上传任意 Python 或只在 GitHub 增加一个文件，不会自动成为可运行的研究组件。新增能力需要在仓库实现、注册受支持规格、验证数据与交易约束、补充测试及实验限制，再部署对应集群执行器和网页/API。正式实验结果落盘归档后才通过只读通道被网页读取。

模型候选训练、验证和人工激活分开。当前周期政策 OFF 时不会自动训练或替换 ACTIVE。恢复 HALT 需要针对具体账本的新的人为授权及成功对账；网页刷新、部署和历史回测都不构成授权。实盘始终关闭。

## 本轮验收边界

工程测试、Linux 全池导出、集群发布、公网 API 与网页构建分别提供证据。今天完整交易日后的真实日版本、预测、候选验证和跨日账本必须以实际产物验收，不能用盘中快照或合成时钟替代。多年历史和完整历史 PIT 仍取决于可核验数据来源；未知的历史状态继续明确列为限制。
