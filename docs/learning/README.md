# QTrade 网站学习手册

核对日期：2026-10-25，北京时间。对应网站：[QTrade](https://q-trade-temp.vercel.app/)，重点页面为“策略中心”和“策略研究”。

这套资料的目标是：你能对着自己的网页解释每个主要组件，知道指标如何得到、能支持什么判断、还缺什么证据，再自己决定下一阶段交付内容。它不是新的策略研究结论，也没有修改策略、重跑正式基线或安排新的研发任务。

## 先记住五句话

1. **因子是信息，模型把信息变成预测，策略把预测变成持仓，回测在假设下计算结果。**
2. **模板、即时预览、本地保存、正式实验、注册策略、模拟盘，是不同对象。**
3. **哈希验证说明文件和身份相符；不说明数据无偏，也不说明策略有效。**
4. **行情更新不应改写旧实验；发布新鲜、数据新鲜、实验截止日期要分别看。**
5. **当前研究有价值，但非 PIT 股票池与历史成交约束仍限制结论。**

## 当前已核对的事实

| 对象 | 事实 | 解读 |
|---|---|---|
| 策略中心模板 | 5 个，4 主动＋1 比较基准 | 代码结构已实现，不等于生产有效 |
| 策略中心旧实验 | 11 个原始不可变候选 | 与其他页面的 14 个持久化记录不是同一个目录口径 |
| Qlib 固定基线 | 990/1000 股，2,157,805 条日线，158 特征 | 独立归档，不自动进入旧策略候选表 |
| Qlib 组合区间 | 2024-01-02—2026-10-23 | 678 个组合会话 |
| Qlib IC 标签截止 | 2026-10-21 | 后面两天的未来标签尚未成熟 |
| 分钟因子工作台 | 75 股、15 行业，冻结 BaoStock 五分钟研究数据 | 与当前近期行情、长期扩容任务分开 |
| 120 日固定报告 | 2026-03-03—2026-08-24；1/6 正收益测试折 | 固定的失败诊断，不能用新行情覆盖 |
| 晋级状态 | NOT_ELIGIBLE | 局部检验或归档完成均不自动改变它 |

所有教学中的虚构数字都标为“教学例子”；未标为教学例子的网页数值来自这次界面或本仓库固定实验记录。术语中的“股票日观测”表示一只股票在一个日期上的记录，不是一次交易。

## 保存位置与边界

本目录是学习资料，完整目录一起复制即可保留相对图片和章节链接；指向项目源码及其他工程文档的链接，需要保留本仓库的 docs/learning 目录结构。实际研究流程仍以 [研究操作流程](../RESEARCH_WORKFLOW.md) 和 [Qlib 基线运行说明](../QLIB_BASELINE.md) 为准。

本次也记录了界面差异和未验收项，尤其是104候选响应被拒绝、模板入口初始化差异、旧前向观察1/20与绿色局部门并存，详见 [来源与核对记录](12-sources-and-verification.md)。

当前实盘保持关闭。你不需要连接券商、购买数据或启动模拟盘，就能完成本手册的阅读与只读练习。涉及已有报告的练习不会产生新的独立样本外证据。
