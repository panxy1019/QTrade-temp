# 08｜统计检验、相关性与稳健性

[返回学习目录](README.md)

本章要解决一个问题：看到好结果，怎样判断它是否只是噪声、选参偶然或特定市场状态？统计方法提供有条件的证据，不能替代数据质量与交易可行性。

## 1. 均值、标准差与标准误

均值描述样本中心；标准差描述单次观察的离散；标准误描述均值估计的不确定性。

在理想独立同分布条件下：

    SE(mean) = 样本标准差 / √样本数

股票同日受共同市场影响，日期之间也可能相关，不能简单把 75 股×20 日的 1500 条记录都当作相互独立。增加股票数可以改善横截面估计，但不会凭空创造更多市场年份。

## 2. IC、RankIC 与 ICIR

Pearson 相关：

    Corr(X,Y) = Cov(X,Y) / (Std(X)×Std(Y))

范围在 -1 到 1。正值说明高分与高收益同向；负值说明反向。Spearman 即先对两个变量排名，再算相关；相同数值使用平均名次。

项目的多期因子评价一般先计算每日横截面 IC，再按日期平均，不是把十年所有股票行混在一起只计算一次相关。

    ICIR = Mean(IC_t) / Std(IC_t)

当前旧 QTrade 用总体标准差，Qlib 脚本用样本标准差；本项目展示的 ICIR 没有乘 √252。某些外部报告会年化，直接比较前应核对。

教学例子：IC 均值 0.03、标准差 0.10，ICIR=0.3。不能把它解释为 30% 胜率。ICIR 与组合信息比率的输入完全不同。

## 3. 条件超额与日期聚类

分钟事件里，毛收益条件超额可写为：

    全信号等权均值 - 全部股票日等权均值

另一种做法是每个有信号日先算：

    d_t = 当日信号股票平均后续收益 - 当日全部合格股票平均后续收益

然后对 d_t 按日期等权。这样同一天 30 个信号不会直接当作 30 个独立市场状态。

教学例子：第一天 50 个信号各超额 -0.2%，第二天 1 个信号超额 +1%；按事件权重可能为负，按两天等权则为 +0.4%。因此页面“条件超额”和“日聚类均值”可以不同，甚至符号相反。

这两者主要是毛事件统计，与成本后复合策略收益不是同一个量。

## 4. Newey–West：考虑日期之间的相关

项目对日聚类 d_t 使用 HAC 思想，允许异方差与一定滞后自相关。当前代码采用 Bartlett 权重：

    gamma_k = (1/T) × Σ[(d_t-mean)×(d_(t-k)-mean)]
    LRV = gamma_0 + 2×Σ[(1-k/(L+1))×gamma_k]
    SE_NW = √(max(0,LRV)/T)
    t_NW = mean / SE_NW

滞后 L 当前由样本数规则选取，并限制不超过 T-1。NW 并不会解决幸存者偏差、未来信息、样本太短或多重搜索。[HAC 官方说明](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)

若 t≈0.1，表示估计均值只有约 0.1 个标准误，正优势证据很弱。t>1.96 是本项目部分研究门采用的阈值，不是市场规律。

## 5. 置信区间与 p 值

当前 NW 区间：

    mean ± 1.96×SE_NW

它使用大样本正态近似，并非小样本精确区间。“95% 区间”不能直接解释成“参数有 95% 概率在这个区间”或“95% 机会赚钱”。

若区间包含 0，当前方法未能清晰排除零均值；这不是证明真实效应恰为 0。区间较宽也可能反映样本不足。

p 值表达：在零假设和检验假设成立时，观察到如此或更极端统计量的可能性。它不是“策略无效概率”。当前纯开仓规则批量检验用 NW t 配合双侧正态近似计算原始 p，并同时要求效应方向为正。

## 6. Holm 多重检验

同时尝试很多规则，至少一条偶然显著的机会会上升。Holm 将 p 从小到大排序，按剩余检验数放大，并保证调整值单调。

教学例子：三条原始 p 为 0.01、0.03、0.04，Holm 调整约为 0.03、0.06、0.06。按 0.05 门槛，只有第一条保留。

它控制一组检验的家族错误率，不是提高收益的算法。必须如实定义“这组”包含哪些尝试；只把最后选中的两个拿来校正，会漏掉前面做过的搜索。[多重检验方法说明](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)

## 7. 相关性与去冗余

页面相关矩阵比较连续方向分数，而不只是二元触发信号。|rho| 接近 1，表示规则高度同向或反向；低相关说明不太线性重复，不能证明有效或独立。

当前部分门使用 |rho|<0.90。这是项目阈值。两条都没有预测能力的规则，即使相关性为 0，也不值得直接组合；两个相关规则也可能在某些状态具有不同增量，需要预先设计检验。

## 8. 连续时间块稳定性

分钟模块分成四个连续、不重叠时间块，检查每块是否有信号、正向块比例、最差块，以及单块绝对贡献是否过高。

当前门包括至少 75% 块为正、最大绝对贡献比例低于 60%。2/4 正向不满足 75%。把日期随机打乱再分四块，会失去“是否只在一个时间阶段有效”的问题意义。

时间块均值与组合实际资金贡献仍要分开，不能把某块的统计优势占比当成账户利润归因。

## 9. 滚动样本外

扩展窗口示意：

    折1：前60日训练 → 后10日测试
    折2：前70日训练 → 再后10日测试
    折3：前80日训练 → 再后10日测试

每折选择只用该折之前的数据，测试互不重叠，再拼接测试收益。训练可能包含早先已结束测试段，这是实时滚动学习的常见设计；关键是不能使用该折未来。

不同标签期限需要清除跨边界的未来标签，必要时设置隔离。测试折彼此不重叠，也不自动保证市场状态独立。

“正收益折比例”不等于赢利概率；六折中五折小赚、一折大亏，拼接仍可能亏损。应同时看绝对与超额收益、回撤、每折样本和成本。

## 10. 参数邻域与成本压力

如果只有阈值 7.31bp 有效，7 和 8bp 都失败，可能过于依赖特定样本；邻近参数检验用于观察平滑性。阈值升高还会减少信号，不能只比较均值而忽略样本数。

成本压力保持信号和规则固定，改变 0/5/10/20bp。零成本都亏损，说明问题不只是手续费；只有零成本有效，说明可交易性脆弱。不能看完成本结果再重选赢家并保留原测试名称。

## 11. 行业、个股、留一行业

行业内测试：对每个行业单独运行。留一行业：每次删除一个行业再运行。逐股票：观察单股差异。前五绝对收益占比：看结果是否集中。

这里的“绝对”包含亏损幅度，不一定等于正利润贡献。行业样本只有五只股票时，结果不能代表整个行业。按失败结果事后删股票，需要新的选择协议。

## 12. Bootstrap

Bootstrap 从已有样本重采样，观察统计结果对样本路径的敏感性。独立打乱日期可能破坏时序相关；块方法保留一定连续结构。

当前 120 日报告使用后 60 个测试日，策略和基准共用重采样日期路径，1000 次 paired stationary bootstrap，期望块长 10 日；展示超额中位数、5%/95% 分位和超额为正的频率。

“5.70%”表示这批重采样路径中约 5.70% 超额为正，不是未来实盘盈利概率。Bootstrap 也不会加入历史不存在的新市场状态，或修复选股偏差。[Stationary Bootstrap 方法文档](https://bashtage.github.io/arch/bootstrap/generated/arch.bootstrap.StationaryBootstrap.html)

## 13. 安慰剂/置换检验

在每个交易日保留信号数量，随机换成同日其他股票，重复计算条件超额；比较真实选股是否优于这些随机选择。

当前代码的发现模块使用 499 次置换，单侧经验 p 采用：

    p = (置换结果不低于实际结果的次数 + 1) / (499 + 1)

固定每日数量可以保留市场共同状态和参与频率。它不检验所有可能策略，也不能证明真实成交。查看检验后改规则，仍需记录新增尝试。

## 14. CSCV 与 PBO

当前设计将同一历史切成 8 个连续块，遍历选 4 块作为训练、其余作为互补测试，共 C(8,4)=70 个组合。每组沿用原训练筛选顺序，观察训练赢家在互补部分的排名。

PBO 是训练赢家在互补测试中掉到中位以下的组合比例估计，不是“这条策略未来亏损概率”。原始方法提出用组合式交叉验证评价回测选择过拟合。[原始论文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

排名logit为log(p/(1-p))，p是带并列平均名次的排名百分位；p=0.5时logit=0，当前实现将logit≤0记为落到中位及以下。本项目排名比较同样的“门控、NW t、条件超额”等元组，测试收益另行保存；不能与其他项目按Sharpe或收益单一指标得到的PBO不加区别地比较。“不同训练赢家”和“最常被选”衡量选择是否稳定，不表示哪个候选获准上线。

这些组合会把日历上较晚块用于训练，因此是选择偏差诊断，不能当成严格先过去、后未来的可部署收益。它复用已看过的测试段，不能推翻原时间顺序测试失败。

本项目使用 PBO<25%、组合正超额比例≥60% 等项目门；阈值通过只是局部条件。当前线上 104 候选响应被拒绝，本章解释其代码设计，没有声称本次已成功展示 PBO 结果。

## 15. 延迟与容量压力

执行延迟保持锁定信号，只改变入场时间；若稍晚入场优势消失，研究对价格时钟敏感。容量压力使用信号前已完成 Bar 的成交量，按参与率和整手取整。

“信号前市场状态”使用上一会话至当前开盘已实现的样本池收益方向等事前信息分组，不允许使用当天收盘后的涨跌给10:00信号分类。它测试固定规则在不同状态是否一致，不会自动变成一套状态择时策略。

分钟冻结数据缺少认证原始成交额且价格为前复权，所以可以诊断股数容量，不能直接用复权价格×原始量伪造人民币容量。Qlib 的日频原始金额与复权逆量有另一套合同。

## 16. 什么才叫完整结论

研究应同时交代：效应大小、统计误差、稳定性、多重选择、样本独立性、成本与可实现性。单项 p<0.05、低 PBO、正 Bootstrap 或高 IC 都不能替代其余项目。

“独立因子评价＋统一策略对照”就是先区分信息价值，再固定组合规则测增量；PIT 和交易约束则决定这些结论是否建立在正确历史上。
