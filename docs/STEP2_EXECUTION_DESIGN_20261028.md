# STEP2 并行准备与实施顺序

2026-10-28。本轮交付范围是设计、接口审计和非生产测试准备；STEP1 的真实
收盘、账本、公开交付和网页验收继续独立推进。以下设计不表示新功能已经上线。

## 当前可复用的基础

| 模块 | 通俗解释 | 本轮结论 | 下一项实现 |
| --- | --- | --- | --- |
| Factor Registry | 每个因子的身份证和计算说明 | 已有因子函数、Alpha158 和不可变归档方式，尚无独立登记库 | 登记公式、依赖、输入时点、实现版本和限制；先接既有价量因子及固定版本 Alpha158 |
| Factor Evaluation | 单独判断因子有没有信息、是否稳定、是否重复 | 现有 IC、分组和模型评分诊断可复用；通用逐因子评价任务尚缺 | 版本化评价合同、合格样本账本、指标政策及不可变独立报告 |
| Strategy Registry 接线 | 把信号和组合规则变成可追溯策略 | 现有 StrategySpec/StrategyRegistry、READY 数据绑定和任务原子登记已具备 | 增加 factor_ref/evaluation_ref，保持现有模型策略兼容 |
| Strategy Builder | 在网页选择允许的研究组合并提交 | 当前支持 Alpha158、Ridge/LightGBM、Top-K、持有门槛、仓位与成本等子集 | 增加已登记因子、信号组合和经验证的组合/再平衡选项；复用预览、签名队列及工作器 |

详细依据和接口字段见[因子合同审计](STEP2_FACTOR_CONTRACT_DESIGN_20261028.md)
及[策略接口审计](STEP2_STRATEGY_INTERFACE_AUDIT_20261028.md)。已有参数
`hold_thresh` 是最少持有步数，不能当作任意再平衡周期或固定持仓到期日。

## 研究合同

1. **冻结研究范围。** 从已准入 READY 日版本选择证券与日期，记录实际合格范围、
   剔除原因、数据/日历/复权来源。目标池1500、数据集990、合格模型输入及实际
   预测行数分别保留，不能互相替代。无关 ETF 分钟缺口不阻塞此日频任务。
2. **冻结因子与标签。** 因子登记计算定义及有序依赖；标签单独定义未来收益区间。
   前瞻特征不得使用未来引用。需要拟合的处理器只使用指定训练范围，并保存产物。
3. **声明信息模式。** 真实系统已知模式检查 available_at 和 observed_at；历史
   事后研究明确披露无法认证的可知时间，不能转换成历史 PAPER 准入证明。
4. **冻结评价政策。** Pearson IC、Spearman RankIC、分组、稳定性和冗余信息
   各自记录样本数、缺失理由、常数截面、并列值、ddof、最小样本和分组规则。
   现有函数的 ddof 差异必须显式处理，不能只因指标同名就混合比较。
5. **追加复验。** 新 PIT/复权/样本版本产生新 evaluation_id 和 experiment_id，
   以 revalidation_of 指向原实验。旧实验的输入、指标、限制、失败和结论保留。
6. **按用途隔离。** 因子研究资格不授予模型激活或 PAPER 恢复；未知交易状态
   仍由现有交易链路阻断。策略继续经组合→风险→OMS→执行，实盘保持关闭。

## 开发检查点及完成条件

| 顺序 | 工作 | 完成证据 |
| --- | --- | --- |
| S2-A | 固定 Qlib 原生接口/公式清单；实现最小 Factor Registry | 精确包和源码身份；同名同版本幂等、冲突拒绝、依赖/时点验证；既有信号映射测试 |
| S2-B | 独立日频评价适配与归档 | 手算与 Qlib 对照；常数/并列/缺失/未成熟标签/共同交易日网格测试；结果完整版本绑定 |
| S2-C | 因子结果接入 StrategySpec 与现有注册器 | 单因子、多因子、模型来源区分；引用验证；原模型合同兼容；新数据版本追加而不覆盖 |
| S2-D | 网页 Builder 的允许列表与同一任务队列 | 预览失效/版本冲突/越权拒绝；端到端隔离任务；原生 Qlib Exchange 和 TopkDropout 对照 |
| S2-E | 首个合格日频版本上的正式研究验收 | 完整归档、独立复验、公开 API 与网页验证，逐实验披露偏差；不以此替代 STEP1 的真实前向验收 |

本轮已完成 S2-A 至 S2-D 所需的设计与接口盘点，以及现有接口的测试准备；
表中新增运行能力仍须逐项编码和验收。完整历史 PIT 是独立长期任务，非上述
所有日频研究的总开关。是否可比较由冻结的数据、标签、样本和成本合同决定。
