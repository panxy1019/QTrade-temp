## Required fixes before mutation-ready review

1. **P1: establish the attempt journal directory durably before any signal (lines110–113,129–137).** The constructor can create the root, while append only fsyncs the phase file and that root. It does not fsync the containing parent entry that created the root. A crash can therefore lose the entire newly-created attempt directory, including an otherwise fsynced TERM_INTENT; an operator resumed during drain could see an empty journal and issue TERM again. Require an already durable attempt directory or fsync the parent and any newly-created ancestors before any leaf action. Directory-sync failure must prevent all wrapper/signal actions. Preserve the existing intent-without-result no-replay behavior.

2. **P1: bind production-equivalent filesystem and actual runtime-budget gates (lines75–82).** The draft verifies elapsed/state/source/freeze and equality of a policy-hash field, but no filesystem identity/mount evidence is present and the policy hash itself need not even be a valid digest. The earlier overlay output is known to be insufficient. Require the cold and warm evidence to bind the same explicitly reviewed production-equivalent NFS filesystem/device/mount and isolated output directory; cold must start without object files. Bind an actual reviewed policy document with export45seconds, physical source512,000,000bytes, decoded cache128,000,000bytes and ordinary Git90seconds, with measured source/cache/counts within limits. Bind exact output index/object identities to the complete independent oracle. Merely supplying matching arbitrary strings cannot establish those properties. The parent is preparing the actual gate schema; this draft cannot waive it.

3. **P1: make and verify the recoverable wrapper backup before replace (lines218–233).** Backup-file fsync is retained, but its parent directory is not synced and its path is unconstrained. Require the backup under the bound, non-aliased attempt root, verify the exact captured old bytes against the reviewed old digest, and fsync the backup parent/new ancestors before replacing the real wrapper. Capture and hash the actual candidate raw bytes once immediately before writing; do not rely only on an earlier check of the candidate path and a post-replace discovery that different bytes were installed. A backup/dirsync/raw-hash failure must leave the wrapper unchanged and prevent TERM.

4. **P2: complete the observation contract before calling a handover successful (lines253–272).** `NEW_RUNNING` currently proves native state and a callback's source/import assertions, then returns after-controls without checking them. It does not prove the old owner's natural exit/owned-child cleanup, exactly one automatic restart, or unchanged unrelated owners/risk/approval/books. Keep this label as a provisional observation, or add separately bound old-exit/log/cleanup/restart-count receipts and explicit invariant checks. Recheck the observed new /proc identity and native PID after the runtime probe before recording the observation. An absent callback correctly leaves proof pending. Ordinary functional publication acceptance remains separate in either design.
