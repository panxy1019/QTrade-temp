## 数据数量为什么不同

21:46实际公开probe的统一池为**1470只股票+30只ETF，共1500证券**。这和Qlib
当前冻结的日频研究范围不是一个概念，不能用990或预测行数代替整个采集池。

| 数量 | 含义 |
| --- | --- |
| 1500 | 统一采集/展示目标证券池，非全A股覆盖 |
| 1498日频 / 1496分钟 | 该次公开采集目录宣告的ready数；行情索引仍旧，不能据此说这些最新K线已全部公网可读 |
| 990 | 本次Qlib冻结请求范围 |
| 988/988 | Oct28该请求实际合格输入逐股准备完成；不是预测行数 |
| 891 / 889 | 既有serving binding范围 / 当前模型真实分数行数，须按各自档案理解 |
| 886 | signals合格研究范围；不等于通过交易约束的可成交名单 |
| 另一个891股/16会话 | STEP2冻结历史评价范围，不把同数值误当同一用途、版本或时间范围 |

停牌、DATA_GAP和UNKNOWN继续依逐日证据隔离。历史PIT、退市覆盖、复权、
精确交易状态和多年连续分钟数据仍未认证。没有为补齐数字生成缺失K线，
也没有为产生模拟成交放开UNKNOWN交易约束。PAPER的纯现金/零成交和SHADOW
的null收益均保留真实含义，不能称策略已获得收益。
