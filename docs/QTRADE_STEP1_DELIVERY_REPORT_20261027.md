## 2. 现在可以怎样研究

生产研究页提供已核验READY数据版本下拉、Alpha158特征版本及Ridge/LightGBM。
目前只有这些允许列表配置；Qlib官网的所有模型、数据频率和工作流并未全部开放。

```mermaid
flowchart LR
  A[READY不可变数据版本] --> B[特征/模型/切分/组合/成本规格]
  B --> C[受保护预览与签名任务队列]
  C --> D[集群再次校验完整输入]
  D --> E[训练/回测/独立恢复/正式归档]
  E --> F[StrategyRegistry EXPERIMENT与模型工件]
  F --> G[更晚日验证与研究批准政策]
  G --> H[ACTIVE每日预测与signals]
  H --> I[PAPER/SHADOW独立准入与观察]
  E --> J[只读发布与Vercel网页]
  I --> J
```

每份新规格冻结数据version/manifest/dataset/来源快照/READY事件/支持池哈希，
再绑定特征、模型与处理器、标签、训练验证测试区间、TopkDropout、成本和实际源码。
预览产生strategy_version；网页提交携带expected_strategy_version；集群和独立runner
重读本地真实档案。已接受任务不会因“latest”变化自动改绑。

StrategyRegistry记录真实EXPERIMENT与任务关联；成功后另行记录训练模型artifact。
策略生命周期与模型生命周期分开：模型研究激活不自动把策略晋级为PAPER，更不授予实盘权限。

新增因子或模型以后需要仓库实现、允许列表接入、合同与测试、集群对应源码部署。
GitHub main的网页代码会触发Vercel构建；这不会自动执行任意新增Python文件，也不会
自动替换集群冻结源码。日数据和研究结果通过持续只读发布更新，不需要为每次行情重建网页。

## 5. 网页职责与已退役范围

- 策略研究：配置不可变研究规格、预览、登录提交、查看任务状态。
- 实验中心：正式任务、归档、实际输入与来源审计；失败/取消同样保留。
- 回测分析：选定正式结果的曲线、指标、配置及限制，不混同实时账户收益。
- 在线模型：TRAINED/验证/ACTIVE与批准政策、滚动政策；训练完成不等于可执行。
- 每日研究信号/模拟交易/持仓：预测、目标与实际模拟执行分开。
- 数据中心：目标池、当前覆盖、质量、新鲜度与缺口；历史证据不改成新证据。
- 历史工作区：旧ETF/75股分钟研究、固定120日因子报告和浏览器本地历史记录。
